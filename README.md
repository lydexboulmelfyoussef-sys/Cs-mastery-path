# CS Mastery Path

Parcours personnel : Python (fonctionnement, bonnes pratiques) → POO → Algorithmique → ML/Data → TensorFlow.

Pour chaque sous-module : un notebook de cours (`00_cours.ipynb`), puis des notebooks d'exercices guidés par niveau
(`01_exercices_easy.ipynb`, `02_..._medium.ipynb`, `03_..._hard.ipynb`), puis un projet (`04_projet.ipynb`) quand le
sujet s'y prête.

Voir [ROADMAP.md](ROADMAP.md) pour l'avancement.

## Ouvrir un notebook depuis le téléphone

1. Ouvrir ce dépôt sur GitHub dans le navigateur du téléphone, naviguer jusqu'au notebook voulu.
2. Dans l'URL, remplacer `github.com` par `githubtocolab.com` (ou préfixer avec
   `https://colab.research.google.com/github/`), par exemple :

   `https://colab.research.google.com/github/<ton-compte>/cs-mastery-path/blob/main/00_setup/00_cours.ipynb`

3. Le notebook s'ouvre dans Google Colab, exécutable directement dans le navigateur, sans rien installer.

## Installation locale (optionnel, sur PC)

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
